# F.R.I.D.A.Y.

Локальный голосовой ассистент «Пятница»: интерфейс в браузере, голосовые команды,
запуск приложений и сайтов, напоминания, память, живой разговор с локальной LLM
и Telegram-бот. **Windows · macOS · Linux.**

## Запуск

Нужен **Python 3.10+**. Больше ничего ставить не надо — только стандартная библиотека.

| ОС | Как запустить |
|---|---|
| **Windows** | двойной клик по `run.bat` |
| **macOS** | двойной клик по `Friday.command` |
| **Linux** | `./run.sh` |

Или вручную: `python3 server.py` → открой `http://127.0.0.1:8765` → нажми
**АКТИВИРОВАТЬ** и разреши микрофон.

Без браузера: `python3 server.py --no-browser`.
Голосовой ввод работает в Chrome, Edge и Safari.

## Что умеет

| Скажи | Что произойдёт |
|---|---|
| `запусти яндекс музыку` | откроет приложение |
| `в браузере открой сайт решу егэ` | откроет сайт |
| `открой вк и яндекс музыку` | две команды из одной фразы |
| `какие папки я открывал в vs code` | история проектов |
| `найди информацию про переговоры` | выжимка из источников + кнопки «открыть» |
| `порешать информатику` | откроет Решу ЕГЭ, папку с материалами и последний файл |
| `громче` / `тише` / `пауза` / `следующий трек` | управление музыкой |
| `статус системы` | RAM, диск, батарея, uptime |
| `напомни через 10 минут позвонить` | таймер и уведомление |
| `запомни, что я не люблю шум` / `забудь, что я люблю рок` | память: добавит или удалит |
| `сделай скриншот` | снимок экрана: откроет и покажет в чате |
| `найди файл договор` | поиск файла по имени |
| `посчитай 12*8+4` | калькулятор |
| `сгенерируй пароль на 20` | надёжный пароль |
| `какая погода в Москве` / `курс доллара` | погода и курсы |
| `добавь задачу купить хлеб` / `мои задачи` | список дел |
| `напомни каждый день в 9:30 пить воду` | ежедневное напоминание |
| `выключи wifi` / `заблокируй экран` | управление системой |
| `что я делал сегодня` | история команд |
| `поговорим` или любой вопрос | ответ LLM |

Полный список — скажи «что ты умеешь». Команды в одной фразе («и», «потом», запятая)
выполняются параллельно.

## Голос

1. **macOS** — встроенный `say` (голос Milena), работает сразу и офлайн.
2. **Piper** — локальный нейроголос, самый быстрый. В репозитории его нет (60 МБ модель
   и Windows-бинарники): положи модель `ru_RU-irina-medium.onnx` в `data/piper/`,
   а бинарник — в `vendor/piper/` (Windows-сборка: <https://github.com/rhasspy/piper/releases>)
   или поставь `pip install piper-tts` (macOS/Linux).
3. **edge-tts** — красивее, но нужен интернет: `python -m pip install --target vendor edge-tts`.
4. Иначе — голос браузера.

Модель Piper: <https://huggingface.co/rhasspy/piper-voices> → `ru/ru_RU/irina/medium`.
Движок выбирается в Настройках.

## Живой разговор (LLM)

```bash
ollama pull qwen2.5:7b    # один раз
ollama serve              # или запусти приложение Ollama
```

Настройки → «Живой разговор» → **Проверить**. Если нужной модели нет, Пятница сама
возьмёт любую установленную, а кнопка **«Скачать модель»** поставит её в один клик
(с прогрессом). Ollama, установленная но не запущенная, поднимается автоматически.
Без модели ассистент продолжает работать командами и офлайн-фразами. Подойдёт любой
OpenAI-совместимый API.

## Как она разговаривает

Пятница — «ваш помощник с искусственным интеллектом», обращается на «вы» и «сэр»,
не упоминает Marvel, не льстит и не приписывает себе ваши вкусы. Ответы — 1–3
предложения. На «найди…» сначала даёт краткую выжимку с источниками и предлагает
открыть страницу, а не молча открывает поиск.

## Telegram-бот

1. Напиши **@BotFather** → `/newbot` → скопируй токен.
2. В Пятнице: Настройки → **ТЕЛЕГРАМ-БОТ** → вставь токен → «Запустить бота».
3. Напиши боту **`/start`** — он пришлёт твой `chat id`.
4. Впиши этот id в «Разрешённые chat id» → «Сохранить».

Дальше просто пиши боту: `открой ютуб`, `статус системы`, `напомни через час позвонить`.
Команды: `/status`, `/memory`, `/tasks`, `/card`, `/shot`, `/id`. Память, правки и
напоминания общие с веб-интерфейсом.

Бот использует возможности Telegram по максимуму: HTML-разметка (жирный, код, ссылки),
инлайн-кнопки под каждым ответом («Ещё раз», «Задачи», «Скриншот», «Статус»), реакции
👀/✅ на сообщения, статус «печатает», фото скриншота прямо в чат и голосовые ответы
(включи `telegram.voice` в `data/settings.json`). Команда `/card` отправляет
**виджет-карточку** через новый `sendWidget` (Bot API 10.4): если клиент или сервер
его ещё не поддерживает, карточка автоматически превращается в обычное сообщение.

Токен можно хранить и вне интерфейса: переменная `FRIDAY_TELEGRAM_TOKEN` или
`data/settings.json` → `telegram.token`. **Пока список chat id пуст, бот отвечает всем.**

## macOS: разрешения

- **Микрофон** — разреши браузеру (Системные настройки → Конфиденциальность → Микрофон).
- **Медиа-клавиши** (`пауза`, `следующий трек`) — дай Терминалу «Универсальный доступ»,
  иначе macOS не даст их нажимать. Громкость работает без разрешений.

## Диагностика

```bash
python3 server.py --doctor        # голоса, LLM, VS Code, свободен ли порт
python3 tools/selftest.py --tts   # 107 автотестов
```

## Структура

```
server.py           HTTP-сервер и API
core/               разбор команд, действия, навыки, LLM, память, голоса, Telegram, system
web/                интерфейс (HTML + CSS + JS, без сборки)
tools/selftest.py   автотесты
run.sh / run.bat / Friday.command   запуск
```

Каталоги `data/` и `vendor/` в репозиторий не входят: там личная память, кэши и
тяжёлые бинарники. Всё нужное создаётся при первом запуске.

## Что нового в 2.2

Скриншоты, поиск файлов, калькулятор, пароли, погода и курсы, список задач, ежедневные
напоминания, Wi-Fi и блокировка экрана, история команд. Ollama поднимается сама, модель
подхватывается из установленных, кнопка загрузки модели с прогрессом. Telegram: HTML,
кнопки, реакции, фото, голос и виджет-карточки.

Команды, память и настройки остаются на диске. LLM по умолчанию локальная (Ollama).
edge-tts и Telegram ходят в сеть только если ты сам их включил.
